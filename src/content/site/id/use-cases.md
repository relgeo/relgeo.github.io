RelGeo dipakai untuk kebutuhan yang membutuhkan source terbaca, geometri deterministik, dan aturan gambar yang tetap bisa dipakai ulang.

## 1. Menyisipkan Vektor Bebas di Markdown

RelGeo menyediakan jalur seperti Mermaid untuk gambar vektor bebas, bukan hanya untuk diagram template terbatas.

Dalam konteks ini:

1. `rg` berguna saat source perlu tetap terbaca
2. `relgeo` berguna saat hasil render perlu langsung tampil

## 2. Technical Drawing yang Mendokumentasikan Diri Sendiri

Technical drawing adalah domain awal yang paling dalam. Relasi, ukuran, perhitungan, dan intent konstruksi tetap terbaca di source.

## 3. Drafting Parametrik

RelGeo cocok saat satu aturan gambar perlu dipakai ulang dengan input berbeda:

1. data berubah
2. parameter berubah
3. variasi gambar berubah
4. intent authoring tetap satu keluarga

## 4. Gambar yang Tetap Bisa Dibaca Mesin dan Manusia

Use case ini penting untuk:

1. version control
2. review
3. audit
4. automation
5. integrasi tooling

Source tetap layak dibaca dan diproses, bukan hanya diteruskan ke renderer.

## 5. Surface Authoring yang Lebih Kaya di Masa Depan

Surface penggunaannya dapat bertambah:

1. markdown
2. playground
3. CLI
4. desktop app
5. integrasi editor atau doc-site

Markdown embed dan technical drawing sama-sama penting, tetapi keduanya bukan batas identitas RelGeo.
